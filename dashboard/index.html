Versões do macOS compatíveis

O macOS 27 Golden Gate exige Apple Silicon: o macOS 26 Tahoe é o último que roda em hardware Intel/AMD com OpenCore.

Scanner de hardware

O HackCheck lê o hardware deste PC diretamente. Nada é enviado para a internet.

O navegador não consegue ler o hardware do PC. Rode o script abaixo no PowerShell do Windows: ele copia um JSON para a área de transferência. Cole o resultado na caixa e clique em Analisar.

$o=[ordered]@{cpu=(Get-CimInstance Win32_Processor|Select -First 1).Name;gpu=@(Get-CimInstance Win32_VideoController|%{$_.Name});board=(Get-CimInstance Win32_BaseBoard).Product;ram=[math]::Round((Get-CimInstance Win32_ComputerSystem).TotalPhysicalMemory/1GB);net=@(Get-CimInstance Win32_NetworkAdapter|?{$_.PhysicalAdapter}|%{$_.Name});audio=@(Get-CimInstance Win32_SoundDevice|%{$_.Name});disk=@(Get-CimInstance Win32_DiskDrive|%{$_.Model})}
$o|ConvertTo-Json -Compress|Set-Clipboard

Mapeamento de portas USB

Sem o mapeamento, portas USB 3 podem não funcionar ou o limite de portas do macOS pode travar o instalador. O mapeamento é feito depois do primeiro boot, com o hardware real.

  1. Inicie o macOS (ou o Windows/Linux, pois o USBToolBox funciona nos três) e baixe o USBToolBox.
  2. Abra a ferramenta e clique em Discover Ports.
  3. Plugue um pendrive USB 2.0 e depois um USB 3.0 em cada porta física, uma por vez, e aguarde o reconhecimento.
  4. Na aba Select Ports, desmarque as portas sem uso e marque o tipo de cada conector (USB 3, USB 2, interno/Bluetooth).
  5. Gere o UTBMap.kext e coloque em EFI/OC/Kexts, junto do USBToolBox.kext, e atualize o config.plist (ProperTree, Snapshot).
  6. Reinicie e teste todas as portas. Remova patches de limite de portas apenas se o mapa tiver 15 portas ou menos por controlador.

Criar o pendrive de instalação

💡 No programa HackCheck para Windows este processo é automático: ele baixa o macOS da Apple, formata o pendrive e copia tudo. Aqui no site fica o passo a passo manual.

    3. EFI (configuração do OpenCore para o seu PC)

    A EFI precisa ser feita para a combinação exata do seu processador, placa-mãe, placa de vídeo, rede e áudio. Por isso não existe um "download universal": o jeito mais seguro é gerar a partir do seu hardware.

    Siga estes passos na janela preta do OpCore Simplify que abriu:
    1. Se aparecer "Do you want to skip the update process?", digite yes (o HackCheck já baixou a versão mais nova). Se perguntar sobre instalar o Python, digite y.
    2. No menu, digite 1 (Select Hardware Report) e Enter.
    3. Digite E e Enter para ele ler o hardware deste PC. Aguarde a análise.
    4. Quando aparecer a lista de versões do macOS, digite o número de Sequoia e Enter. Nas outras perguntas, aceite o padrão com Enter.
    5. De volta ao menu, digite 6 (Build OpenCore EFI) e aguarde o download dos drivers.
    6. Pressione Enter nas telas finais ("Before Using EFI" e "Result"). Pode fechar a janela depois.

    O HackCheck detecta a EFI sozinho quando ela ficar pronta. Não precisa procurar a pasta.

    ⚠ EFIs de outras pessoas só funcionam se o hardware for igual ao seu (mesma placa-mãe, CPU da mesma geração, mesma GPU e versão de BIOS próxima). Prefira repositórios atualizados recentemente, com OpenCore 1.0.x, e nunca use uma EFI com SMBIOS e número de série de outra pessoa. Depois de baixar, extraia o ZIP e escolha a pasta EFI em "Usar uma EFI que já tenho": o HackCheck confere tudo.

      2. Ligue o cabo de rede. O instalador baixa o macOS pela internet; o Wi-Fi normalmente não funciona nele.

      3. Dê boot pelo pendrive no menu de boot: ASUS F8 · Gigabyte F12 · MSI F11 · ASRock F11 · Dell F12 · Lenovo F12 · HP F9.
        4. 

      4. No OpenCore escolha macOS Base System. Em Utilitário de Disco, apague o SSD de destino como APFS / Mapa de Partição GUID e depois Reinstalar o macOS.
        5. 

      5. Depois de instalar, copie a EFI do pendrive para o SSD, faça o mapeamento USB e gere um SMBIOS único.

      Travou? Erros mais comuns
        

      • Para em EndRandomSeed ou EXITBS:START: quirks de Booter ou CFG Lock. Ative AppleXcpmCfgLock.
        • 

      • Buffer Too Small / Memory pool allocation failure: ative Above 4G Decoding e desative CSM.
        • 

      • Waiting for Root Device / sinal de proibido: problema de USB. Use uma porta USB 2.0 e revise o mapeamento.
        • 

      • This version of Mac OS X is not supported: SMBIOS antigo demais para a versão do macOS.
        • 

      • Tela preta com GPU AMD: adicione o boot-arg agdpmod=pikera.
        •

      Documentação e contribuição
      

      Arquitetura
      

      1. Scanner (PowerShell/Python): coleta CPU, GPU, placa, rede, áudio, discos e exporta JSON.
        2. 

      2. Motor de regras (esta dashboard): compara o JSON com a base RULES e calcula veredito e macOS máximo.
        3. 

      3. Gerador de EFI: chama o OpCore Simplify com o hardware report.
        4. 

      4. Criador de pendrive: baixa o instalador (gibMacOS), formata em GPT/FAT32 e copia a EFI.
        5. 

      5. Mapeamento USB: pós-instalação, via USBToolBox.
